# 照夜界：灵潮将起

一款可以直接在浏览器游玩的修仙文字冒险游戏。双击 `index.html` 开始，不需要安装依赖或启动服务器。

开场会先交代主角在现代世界触发异变、被青铜镜片与天隙共鸣带入照夜界的经过。随后通过救人、观察异象或暂避风头，以及与当地人的对话，逐步了解断天之变、灵潮、各方势力和主角暂时无身份、无修为的处境，再决定是否加入势力。

玩家从苍梧渡醒来，可加入剑宗、丹谷、赤烬教、万方商盟、大晟巡灵司或百族会盟，也可以留在坊市做散修。人物只会在旅途相逢后进入人物簿；入门后可以从两位风格不同的师父中择一，并逐步认识三位同门。师门情分、师父信任和门内人情会影响修行、战斗与最终封阵。每次事件处理完才开放自行安排，可修行、休整、访友、接委托、制作补给或远行。

八个主要地区各有两段地点支线；剑宗、丹谷、赤烬教和商盟驻地也各有两段专属支线。选择会留下本地记录，并在后续事件、世界简报、师门关系和天隙结局中回响。师兄弟姐妹会在门内事件里逐步认识，不会提前列入名册。六位可发展感情的角色拥有不同的性格、底线和互动选择；道侣会继续处理自己的目标。玩家也可结交朋友、与灵兽结伴、带最多三位同伴同行或独自战斗，也能逃跑与躺平。

地图包含苍梧渡、青篁林、雾岭药谷、天隙外沿、云京驿城、霜河关、百药泽和千岛渡。新区域的调查结果会影响第一卷天隙事件的可选结局。

旅途中还可能低概率遭遇重大灾厄：苍梧渡会遇到枯骨门夜袭，各地会发生与地貌有关的天灾，天隙余波也可能波及低阶修士。躺平与高压时局会提高灾厄出现机会；救援、调查和撤离会改变伤亡、压力与最终结局支援。极低修为者可能被高阶斗法余波当场误杀，死亡会记入轮回碑，可开启下一世。

## 文件

- `index.html`：游戏页面
- `style.css`：界面样式
- `game.js`：地点支线、师门关系、人物性格与互动、重大灾厄、委托、制作、战斗、世界推进与本机存档
- `assets/zhaoye-world.png`：原创世界场景插画
- `assets/portraits-first.png`、`assets/portraits-second.png`：六位女修的独立头像素材
- `assets/portraits-support.png`：四位同行人物的独立头像素材

进度保存在当前浏览器的本地存储中。原有版本存档会在读取时补齐新增数据；更换浏览器或清理站点数据后，存档不会自动迁移。

## 在线游玩

仓库推送到 `main` 后，可通过 GitHub Pages 在线游玩：<https://liu7866.github.io/zhaoye-jie/>。首次发布时，在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**；之后每次推送到 `main` 都会自动部署。
